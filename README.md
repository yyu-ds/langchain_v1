# LangChain & LangGraph Learning Repository

A personal learning repository for exploring LangChain and LangGraph concepts through hands-on demos and exercises.

## 📚 Course Structure

```
demos/
├── 01_basics/          # LangChain fundamentals
├── 02_chains/          # Building chains and pipelines
├── 03_agents/          # Agent development
├── 04_memory/          # Memory and conversation history
├── 05_rag/             # Retrieval Augmented Generation
└── 06_langgraph/       # LangGraph workflows and state machines
```

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- OpenAI API key (or other LLM provider keys)

### Setup

1. Create and activate virtual environment:
```bash
python3 -m venv venv
source venv/bin/activate
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Set up environment variables:
```bash
cp .env.example .env
# Edit .env with your API keys
```
